# 策略指标分类与日 K 微观因子

本次功能主归属为策略研究，复用本地 ETF 日行情与现有条件引擎。
目标是区分数据来源，并支持短窗口量价研究；不保证半年内必有信号，
不根据回测收益自动选择参数。保持买卖每组全部或任一满足，不增加嵌套逻辑。

## 指标组织

指标库共十七类，按来源分为 ETF 日 K（十类）、关联指数估值（五类）、
市场／行业恐贪（一类）、国家队持仓估算（一类）。分组默认展开，左库内滚动，
桌面买卖区与下一步保持首屏。统一说明入口保留，不在每个指标重复说明。

ETF 日 K 的十类包括旧均线乖离率、动量、波动率与新增七类。
估值和其他外部因子仍按明确映射与源日期逐日核验，缺失不填零、不前填。

## 计算与预热

价格类复用含分红序列，初值 100，每日乘以（收盘价＋当日除息现金）÷前收盘。
该序列与日 K 图的原始收盘价均线口径不同。均线含当日，N、S、L、K 均为交易日。
短窗口 S 至少 2 且小于长窗口 L，均线窗口不超过 250；比较间隔 K 为 1 至 250。

| 指标标识 | 计算 | 最少收盘点 |
| --- | --- | --- |
| `trend` | （含息值÷N 日均线－1）×100%，展示名为均线乖离率 | N |
| `momentum` | （含息值÷N 日前含息值－1）×100% | N＋1 |
| `volatility` | N 个日含息收益的总体标准差×√252×100% | N＋1 |
| `ma_spread` | （S 日均线÷L 日均线－1）×100% | L |
| `ma_slope` | （N 日均线÷K 日前的同窗口均线－1）×100% | N＋K |
| `price_cross` | 含息值穿越 N 日均线 | N＋1 |
| `ma_cross` | S 日均线穿越 L 日均线 | L＋1 |
| `volume_ratio` | 当日成交量÷此前 N 日均量，分母不含当日 | N＋1 |
| `volume_ma_ratio` | S 日均量÷L 日均量，两者含当日 | L |
| `breakout` | 含息收盘值严格高于此前 N 日最高收盘值或低于最低值 | N＋1 |

上穿要求昨日差值≤0且今日差值＞0；下穿要求昨日≥0且今日＜0。
持续高于均线不会重复触发交叉。突破只比较此前窗口，等值不成立；
连续创新高可以连续突破。事件参数仅显示方向，不要求输入事件数值阈值。
规则沿用 `threshold` 字段占位，但事件计算不使用它；窗口参数新增 `long_window`、`lag`。

成交量使用同标的源单位，比值单位相消，不称盘中量比；缺量或分母为零不可判断。
因子层保留有效零成交量，但完整历史模拟沿用原数据门禁，零成交量或无法确认停牌
依然拒绝回测。国家队变化预热修正为 N＋1 点，与原计算实际要求一致。

## 诊断与快照兼容

统一比较冻结规则、原行情与外部因子。结果另存 `condition_diagnostics`，
包含每条件满足／有效／缺失天数、买卖整组满足天数和实际模拟买卖笔数。
诊断决策日从区间首个执行日的前一交易日起，到末执行日前一交易日止；
排除更早预热和区间末日收盘后无法执行的判断。

条件成立不等于实际模拟成交：买卖同时满足卖出优先，持仓中不重复买入，
现金不足或整手限制也可能阻止成交。原失败门禁保持：任何条件资料未知均拒绝该候选，
即使组为任一满足也不掩盖未知。失败对象保留具体条件与日期。

新增目录版本 `catalog_version=1.1`；计算版本保留 `1.0`，旧指标公式、证据名称和
旧账户结果不改。新指标使用独立标识，新增参数随规则与输入摘要冻结。
仅前端显示 `trend` 的新名称，旧证据仍保留原名。旧比较没有诊断字段时不补造数据；
新比较复算同时检查诊断，旧比较继续只核验原账户。无需数据库结构迁移。
