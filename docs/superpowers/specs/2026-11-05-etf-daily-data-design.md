# ETF 历史日行情首期设计

本设计覆盖标的配置、定时采集入库和日 K 展示，已获用户确认并完成首期实现。
主归属为数据基础，日 K 展示协作归属投研分析。不包含实时行情、策略或交易信号。

## 页面与范围

沿用 Ledger Terminal 设计契约，导航只开放本期三个入口。

- 标的配置：预置 510500、512100、159531、159205、588080。支持启用或停用采集、
  设置历史采集起始日期，展示数据来源、已入库数量和最早及最新行情日期。
  代码固定为首期五只，名称以接口返回为准，不猜测。停用不删除已有行情。
- 定时任务：一个日行情采集任务，支持每日执行时间、启停、手动运行及查看运行日志。
  默认北京时间每日 01:00，采集截止昨日；接口只提供历史日数据，不将当天标为完整行情。
  运行中禁止重复触发，展示上次结果、下次执行时间和每只标的处理结果。
- 日 K 展示：从本地数据库读取，支持切换五只标的、日期范围及 1M/3M/6M/1Y/全部。
  展示原始日 K、成交量和当前所选交易日的行情详情；明确价格口径、来源与数据截止日。
  无数据时引导采集，加载失败可重试，不填充演示行情。

## 采集与数据边界

首次按配置起始日期分月回补，后续从最新已存日期回看七个自然日以覆盖近期修订。
默认起始日期为 2020-01-01，可在标的配置调整；上市前无数据视为空响应，
不生成价格为零的记录。调早起始日期后补齐更早区间，调晚不删除历史数据。
空响应不代表已验证数据完整，记录请求区间和返回条数。

截止日采用 Asia/Shanghai 的昨日。每天运行而不内置交易日日历，休市日允许空响应。
失败区间必须保留，下次优先重试，不以更晚数据已存在为由跳过缺口。
单个标的或月份失败不阻断其他标的，整体结果区分成功、部分失败与失败。
超时或临时服务错误采用有界重试；鉴权失败清晰提示配置错误，不记录凭据。

按代码、交易日期唯一约束幂等更新。只接受请求中的标的和日期范围，
校验价格关系、日期与必要字段，拒绝错误数据并记录原因。
成交量与成交额的单位未经数据源确认，在页面标明源单位待确认；
不把 ADJUSTED_CLOSE 当作完整复权 OHLC，不推断前复权或后复权。

## 后端、数据库与调度

继续使用 PostgreSQL、FastAPI 和 React 三服务。后端新增标的配置、日行情、
任务配置、运行记录及采集区间结果，数据库结构通过 Alembic 迁移。
行情保留源更新时间和本地采集时间，价格使用定点数，成交量额避免整数溢出。

API 内运行轻量调度，数据库锁保障定时与手动触发互斥；配置与日志持久化。
重启后恢复调度，未结束的运行标记中断并允许重试，未完成区间继续处理。
任务在后台执行，请求立即返回运行编号，页面轮询状态；不引入 Redis 或额外 worker。

提供标的查询及配置更新、任务查询及配置更新、手动运行、日志和日行情查询接口。
查询参数校验日期先后及范围；历史行情只走本地数据库，页面查询不触发外部采集。

数据源 URL、access code 和 Bearer token 由后端环境变量配置，
示例文件只声明变量名，不写真实凭据。前端、数据库日志和仓库均不保存凭据。
迁移只针对本地项目数据库，不操作外部生产数据库。
