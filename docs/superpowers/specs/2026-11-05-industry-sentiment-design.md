# 行业恐贪历史数据设计

用户要求收集和展示源页面的行业恐贪历史数据。本设计已确认并实施；采集方式按用户补充改为首次五年、后续增量。
功能主归属数据基础，展示协作归属投研分析；不直接产生策略或买卖信号。

## 已核实的数据源

2026-11-05 实际查询全部成功。源目录接口为
`https://ai2.jiucaishuo.com/api/tools/industry-fear-greed`，返回可用类别和最新快照。
历史接口为同路径下 `/series?key={key}&years={years}`，返回名称、关联指数与
按交易日排列的 `date`、`value`、`close`，并非实时行情。

| key | 源名称 |
| --- | --- |
| gf | 军工恐贪 |
| qs | 券商恐贪 |
| energy | 新能车恐贪 |
| gfu | 光伏恐贪 |
| dc | 电池恐贪 |
| hj | 黄金恐贪 |
| zj | 固收+恐贪 |
| cnn | 美股恐贪 |

目录中的名称与实际序列返回为准，不按英文 key 猜行业，不建立 ETF 对应关系。
源接口不需要用户提供的 ChatBI 凭据，两类数据源严格分开。

## 采集与存储

新增独立的“行业恐贪日数据”任务，复用任务页和运行日志交互，不改动 ETF 采集规则。
默认北京时间每日 01:10，支持启停、手动执行及单独日志、互斥和失败重试。
默认覆盖源页面当前八类。每类别首次下载五年；后续以本地最大日期为水位，
仅写入水位前七日以来的数据，含近期修订。源最小有效下载窗口为一年，
日期起止参数实际不生效；停采较久时选择三年或五年窗口。若源窗口无法覆盖
旧水位则报断档，不静默跳过。源新增类别通过目录发现，仍首次下载五年。

保存类别 key、源名称、关联指数名称、启用状态、交易日期、0–100 恐贪值、
指数收盘价、源快照标签及本地采集时间。以 key 和日期唯一约束幂等更新。
成功类别单独提交，失败不清空旧数据；运行区分成功、部分失败和失败。
源返回空序列保留明确的空结果日志，不覆盖或删除已经保存的历史数据。
使用 Alembic 增加表结构，既有 ETF 任务和数据保留。

日期按数据源原值保存，不套用 ETF 截至昨日规则。特别是美股当前快照为
2026-11-05，其他七类为 2026-11-04，不猜测源时区或其收盘归属。
校验日期、数值范围与类别一致性；0 是有效值，null 才是缺失。
源值小于 0 或大于 100 不入库，拒绝非有限数字和重复日期冲突。
源未提供历史情绪标签或计算公式，不自行补造阈值或历史分类。
最新快照标签仅在日期和值与历史对应点一致时关联展示，来源与时间明确。

## 展示

新增“行业恐贪”入口，以八类最新分数总览和单类别历史曲线组成。
支持切换类别、1Y/3Y/5Y、本地日期范围、历史明细、手动采集入口。
展示最新分数、关联指数收盘价、源日期、本地采集时间、源标签及实际覆盖范围。

按用户调整，恐贪分数与指数点位合并为同一张双轴图，日期、提示框和缩放共享。
左轴固定0–100，右轴为指数点位；分数连续蓝灰琥珀着色，指数使用紫色虚线。
情绪表达使用本项目恐惧蓝、贪婪琥珀和中性灰，不复制源页面的红绿语义。
卡片依据源最新标签渲染恐惧蓝、贪婪琥珀和中性灰，并保留文字；
曲线色阶不表示情绪分类阈值，不根据历史分数推断源状态。
空数据、加载、请求错误和重试状态完整实现，不生成演示数据。
