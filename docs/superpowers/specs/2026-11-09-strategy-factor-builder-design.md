# 创建策略因子拖拽配置设计

本文记录拖拽配置台初版范围。后续十七类来源分组、规则参数扩展与触发诊断见
[微观因子设计](../specs/2026-11-09-strategy-micro-factors-design.md)。

本文设计已获用户确认，并按用户截图反馈收紧布局及说明入口。功能主归属为策略研究，入口为“我的策略／创建策略”，
也适用于基于已有版本修改规则。

## 目标与范围

把现有纵向条件表单改为因子拖拽工作区，默认展示全部十类指标，让用户在同一屏幕
完成规则配置。沿用现有指标、规则引擎、草稿、回测比较、保存和启用流程。

买入组与卖出组分别选择“全部条件满足”或“任一条件满足”。不增加嵌套条件、
否定运算、连线画布、新指标或后端数据结构。

## 布局选择

推荐左侧指标库、右侧买卖并排配置的布局。它能同时展示指标与买卖规则，适合本次
单层条件组。备选为左侧指标库配买卖切换标签，可增加单组宽度，但无法同时核对
买卖条件，因此不采用。自由连线画布增加操作成本，也不符合本次逻辑限制。

```text
创建策略 · 当前 ETF                              返回版本列表
配置规则 → 回测比较 → 保存与启用
策略名称                 模板                  投入比例
┌────────────────┬────────────────────┬────────────────────┐
│ 全部指标       │ 什么时候买         │ 什么时候卖         │
│ 趋势／动量／波动│ 全部满足／任一满足 │ 全部满足／任一满足 │
│ 估值           │                    │                    │
│ 国家队／恐贪   │ 拖入指标后设置     │ 拖入指标后设置     │
│                │ 窗口、比较、阈值   │ 窗口、比较、阈值   │
└────────────────┴────────────────────┴────────────────────┘
规则摘要／数据提示                       下一步：回测比较
```

默认指标库不折叠、不要求点击“更多指标”，以紧凑列表展示全部已注册指标。
指标使用现有中文全称和单位，可按行情、估值、资金与情绪分组，不隐藏暂不可用指标。
颜色、字体、焦点与状态语义沿用现有设计契约，不引入新的视觉体系。

## 拖拽与条件编辑

从指标库拖入买入区或卖出区，会复制生成一条条件，指标库中的原指标始终保留。
落点所在条件组追加新条件，拖入过程中明确高亮目标组，落在组外或取消拖拽不改变草稿。
本次不提供组内排序和跨组移动，条件顺序不改变全部或任一满足的含义。

每条条件显示指标名，以及该指标适用的窗口、比较符、阈值与单位；恐贪额外要求
显式选择类别。支持删除条件。同指标可以重复添加以设置不同窗口或阈值，重复时提示。

保留现有默认趋势规则、模板和草稿恢复。新增条件复用现有默认参数行为，参数仍可修改；
不把默认参数描述为推荐配置。每组沿用至少一条、最多二十条的限制，并在界面明确提示。

指标库同时提供“加入买入”和“加入卖出”的按钮，支持键盘及触屏完成同等操作。
拖拽不是唯一入口，计算或保存中禁用规则编辑及添加操作。

## 指标说明与数据状态

左侧指标栏顶部只提供一个“指标说明”入口，在独立浮层内切换十类指标，展示现有
投资含义、如何理解、计算方式、数据来源与使用边界。支持键盘关闭和焦点返回，
不推移条件与操作栏；指标行与条件卡片不重复放置说明按钮。

数据覆盖、缺失原因与修订历史等重复口径集中在说明浮层中查看。缺数据指标和条件
保留简短“暂不可用”状态，不伪造数据，也不绕过已有回测校验。
资料加载、读取错误和重试使用现有交互。

## 一屏与响应式边界

桌面验收视口暂定为 1440×900 和 1366×768，在正常字号下同时看到完整指标库、
买卖两组配置入口、名称、模板、投入比例和下一步操作。精简当前重复标题与纵向留白，
工作区使用剩余视口高度，条件较多时在组内滚动，不让操作按钮被推到页面底部。

左侧指标库收窄为 260 像素，桌面参数框高 28 像素，按窗口、比较符、阈值和类别
限制宽度，不为短数值拉满整行。1366×768 下同时展示买卖两组各四条常用条件的
完整参数。窄屏恢复较大触控尺寸，避免因紧凑布局牺牲操作。

“一屏”针对配置规则阶段，不把回测结果、历史记录或全部长说明同时塞进一屏。
历史比较仍可在后续阶段查看，已存在的历史快照读取入口保持可达。

窄屏使用纵向布局与点击添加，保证参数可读及操作可达；200% 缩放时允许页面纵向滚动，
不以固定高度裁切控件，不产生页面横向溢出。

## 数据流与兼容

指标库来自现有策略目录，条件变更写入现有买入／卖出条件数组。全部或任一满足
继续映射为现有 all／any。继续使用原草稿自动保存、规则摘要和比较失效判断。
不新增 API、数据库迁移、规则格式或拖拽依赖。

## 实施与验收

按以下顺序实现并验证，功能落地时同步维护 README、功能地图及单 ETF 使用说明。

1. 调整编辑器结构与布局，验证全部指标默认可见、买卖并排及桌面一屏边界。
2. 增加拖拽复制、按钮添加和紧凑条件编辑，验证两组参数相互独立、取消拖拽不修改、
   最少／最多条件限制、恐贪类别及缺失提示。
3. 接入独立说明浮层，验证键盘关闭、焦点返回与窄屏操作。
4. 回归已有草稿、模板、版本修改、比较和保存流程，验证参数修改使历史结果失效，
   实际回测请求仍提交原有规则结构。
5. 执行前端构建、类型检查和浏览器回归，检查双主题、两种桌面视口、390 像素窄屏
   与文字放大，并检查文档链接和差异空白。
