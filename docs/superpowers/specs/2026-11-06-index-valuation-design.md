## 已验证数据接口

页面是单页应用，HTML仅返回应用入口；本次读取其实际脚本中调用路径并实测响应，
没有以猜测路径替代接口发现。公共估值接口本次读取不需要登录凭据。
基础地址为 `https://ai2.jiucaishuo.com/api`。

| 路径 | 参数 | 数据及用途 |
| --- | --- | --- |
| `/index-valuation/categories` | 无 | 规模gm、精选jx等分类目录 |
| `/index-valuation` | `category=gm`或`jx` | 最新估值概览、源标签、源日期与过期状态 |
| `/index-valuation/detail` | `code` | 估值摘要、指标最新值/均值/分位、更新时间 |
| `/index-valuation/history` | `code`、`metric`，可传`name` | 日期/value序列、整段均值/分位阈值和最新分位 |
| `/index-valuation/funds` | `code` | 关联基金目录；只用于映射核验，不采全市场基金 |
| `/index-valuation/constituents` | `code` | 成分及行业权重，本版不纳入 |
| `/index-valuation/forecast` | `code` | 历年财务与预测混合，本版不纳入 |
| `/index-valuation/performance` | `code`、`period`等 | 业绩与回撤，优先由本地指数行情派生，避免重复源 |
| `/index/min-trend` | `code` | 分时，本版明确不请求 |

列表gm返回27行，jx返回13行；它们是同一指数池的分类视图，不能作为两个独立数据源。
中证2000出现在jx，其他7只在gm可找到。列表只将8只相关行落库，其余不纳入研究范围。
不因源分类变动丢弃已配置的相关指数，可以直接按固定映射查询详情和历史。

历史指标保留 `pe`市盈率、`pb`市净率、`xilv`股息率、`roe`净资产收益率、

科创50从2019-12-31开始，股息率从2020-05-07开始；中证2000从2023-08-11开始。
源历史调用没有日期窗口参数，不能宣称支持按日期下载增量。

8只指数2026-11-05收盘均与估值详情一致。ETF价格与指数点位分表、分轴。

## 口径差异与质量边界

来源概览、历史序列与本地统计必须分别命名，不能悄悄替换。

1. 列表/详情PE、PB、股息率可能截断到两位，历史序列保留更多小数。
   例如上证50 PB概览1.22/44.65分位，历史最新1.2251/46.91分位。
   以历史序列作为图表与本地统计值，来源概览分位独立保存并明确标签。
2. 历史响应只有逐日原始指标，没有逐日历史分位。响应顶层percentile及
   p10/p30/p70/p90针对本次返回的整段样本，不能当成过去任意一天已知值。
3. 详情对短历史也可能写“近10年”；本地显示实际起止日和样本数，历史不足可见。
4. 参考的科创综指PB/股息率在指数实际短历史前存在大量零值，说明源可能有占位。
   该指数本版不收集，仍据此为相关指数增加指标有效性和覆盖检查。
   PB、PE非正值不参与有效估值统计，保留原值及不适用/异常原因；
   股息率0有效，风险溢价与ROE允许负值，不统一转成缺失。
5. 列表ROE为小数（如0.0989），历史ROE为百分数（9.89）；入库展示统一为
   百分数并保留来源换算说明。股息率本身为百分数。风险溢价按源差值保存，
   标为百分点；不捏造国债期限或PE是否TTM/等权/整体法等未经证实细节。
6. `stale`、`insufficient`、`not_applicable`、源日期与本地采集时间分别保留。
   源历史缺失、结构变化或尾部倒退必须在运行日志和页面可见，不能清空历史。
7. 分位使用十进制值，保留源精度；不以四舍五入后的显示值重算分位。

## 方案选择

推荐核心日频估值加指数日K，满足历史研究且请求量可控。
只做概览的方案缺乏历史对照；完整照搬成分穿透、预测与相关性则超出本次核心需求。
本版不建设后两者，不把讨论中的未来指标接入策略视作已确认排期。

页面沿用现有设计契约：中文、紧凑筛选、主要指标之后图表为核心，
不另启用视觉方案预览工具，不复刻外站品牌与推荐买卖文案。

## 数据与采集设计

沿用PostgreSQL、SQLAlchemy、Alembic及现有Job/Run调度恢复机制。
新增独立任务4“指数估值”，默认北京时间每日01:30，可手动运行、暂停和重试，
与任务1/2/3的锁、水位和运行记录隔离。无分时轮询，页面加载仅读本地库。

初次读取源可提供的全部5类历史；后续每天完整核验源历史，数据库按
指数/指标/交易日期幂等比较，只插入新增、更新修订记录，未变化不重写采集时间。
某指标失败不推进该指标成功水位，不删除已有数据。保留源回退或缺口异常。
被删除的源点不自动从本地删除。十日历年窗口以前的前端自然过期可保留旧点并继续新增；窗口内缺日或尾部倒退仍失败并记录异常。

指数行情首次从该指数最早有效估值日期回填至北京时间昨日，受实际接口覆盖约束。
按月请求与提交，成功区间留水位；之后按最新成功区间增量并保留七日修订交叠。
长期失败或历史断档独立重试，不能以最新交易日掩盖中间缺口。
只有末尾尚未更新的源日期会被明确标记，不无声补价或向前填充。

任务4中估值与行情分阶段记录结果，估值源无需凭据，行情使用现有后端鉴权；
未配置行情凭据时估值仍可采集，行情部分明确缺失/跳过，整体不报全成功。
不更改现有ETF配置或凭据，不输出鉴权URL/请求头。

必要持久化对象如下，具体字段在实现迁移中保持清晰语义及完整中文COMMENT：

| 对象 | 主键/职责 |
| --- | --- |
| `research_indices` | `index_code`，指数名、ChatBI代码、来源及启停配置 |
| `instrument_index_links` | `instrument_code/index_code`，ETF与研究指数关联及核验依据 |
| `index_valuation_daily` | `index_code/metric_key/trade_date`，源值、有效状态、采集时间 |
| `index_valuation_snapshots` | 观测编号，按指数/观测时点归档来源概览、详情、整段统计及覆盖摘要；最新版本用于概览 |
| `index_valuation_revisions` | 修订编号，按指数/指标/源日期保存每次值或有效状态变更、前后值、观测时点及运行编号 |
| `index_candles` | `index_code/trade_date`，独立指数OHLC点位、量额、源更新时间、采集时间 |
| `index_collection_windows` | 行情按指数/区间的成功/失败进度，恢复回补与修订检查 |

保留每次实际改变的估值输入版本证据（旧/新值、观测时间、源日期及运行编号），
在同一事务中写入当前数据与修订表，首次观察的旧值为空。
来源概览及详情以观测时刻归档，相同内容不重复保存；源日期不当作发布时间。
源行情继续按原始行及源更新时间存储，版本证据重点覆盖估值与其展示口径。

## 分位与图表

新增一个“指数估值”入口，不为规模/精选各建一套页面。
概览只显示8个关联指数的最新主要估值与来源日期；可按当前ETF筛到对应指数，
或切换指数查看详情，并展示关联的当前ETF，不引入源全市场列表。

详情保留：

- 最新PE/PB/股息率/ROE/风险溢价、来源日期、实际覆盖、缺失或过期提示。
- 一张可切换指标的估值历史主图，配实际样本区间及分位说明；同日指数点位用独立轴。
- 日K与成交量，沿用本地A股图表规范及必要均线；指数点位不可称为ETF价格。
- 来源、采集时点、单位及口径说明，可折叠，不出现底部全量明细表。

为了避免未来信息，图上逐日分位由本地明确公式计算：
以该日为截止、最多往前10个日历年内的有效观测，包含当日，
`100 × 严格小于当日值的观测数 / 有效观测总数`。
不把高股息率分位自动解释成高估；不自行加入阈值买卖建议。
数据不足10年明确显示可用年限，不扩展为虚假十年。
这些是“按当前已采历史回看”的本地统计，不是原始时点已发布或当时可获得的分位，
本版不把它无条件用于回测。源顶层分位另列“来源概览分位”，不画成历史逐日值。

源返回的整段分位线若绘制，必须标“当前区间统计参考”，不能称为历史信号。
本地默认使用上述逐日因果统计；显示区间切换只影响可视范围，不偷改分位窗口。
缺日不补零、不同指标独立覆盖，零股息与负风险溢价都可被正确展示。

不收集分时、预测营收利润、全量股票行情、全量成分股穿透、跨指数相关性矩阵。
风险溢价虽保留源序列，但未经核实的计算方法不本地重建。

## 本地接口与验收

本地统一使用 `/index-valuations` 前缀：目录概览、单指数历史与日K、任务配置、
手动触发及运行记录。仅允许配置的关联指数，非法/未配置代码明确拒绝。
具体请求和响应沿用既有API风格，前端不直接调用外源或获取鉴权配置。

验收须包含下列可证实结果：

1. 20个ETF关联覆盖、8个指数去重及000680不被误纳入。
2. PE/PB/股息率/ROE/风险溢价单位、可空、零及负值规则单元测试。
3. 整段历史核验、幂等写入、源修订证据、单指标失败、行情断档恢复测试。
4. 本地分位同值/缺失/窗口/短历史与无未来数据测试，源分位不混用。
5. 任务4与其他任务锁/运行/恢复隔离；参数凭据不泄露。
6. 独立测试库迁移与数据库COMMENT一致；真实8只初采与第二次幂等核验。
7. 图表加载、空、错误、历史不足、过期状态，ETF筛选及亮暗主题检查。
8. 前后端要求检查、Compose配置、文档链接与diff检查；同步README/功能地图/数据字典。
