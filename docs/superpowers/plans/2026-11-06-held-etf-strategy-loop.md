依据[已确认设计](../specs/2026-11-06-held-etf-strategy-loop-design.md)，沿用FastAPI、
SQLAlchemy、PostgreSQL、React和统一回测引擎。本轮在当前目录分支工作，保留之前
未提交内容。分工按业务文件隔离，先业务验收再质量检查。

- [x] ETF主体修正：研究对象及横向比较按ETF组织，关联指数为来源；验证共享映射、旧URL、默认当前持仓。
- [x] 因子与候选：先写含息动量、入场确认、半资金储备及无未来数据测试，再扩展策略注册与研究计算。
- [x] 研究批次：新增带中文注释表与迁移，冻结持仓范围、统一50000元、开发验证区间和所有候选；覆盖缺失与原子保存测试。
- [x] 观察与信号：采用版本、完整数据门槛、时点与幂等、目标数量及真实仓位对照；先测节假日、迟到、T+1和无现金证明。
- [x] 执行核对：人工确认日期与关联，唯一归属、累计数量修订、部分/超额/跳过状态；不把候选匹配当成交证明。
- [x] 页面串联：现有策略页研究/回测/观察入口，图表与风险取舍、明确动作和空错误状态。
- [x] 验证与交付：单元/独立测试库、类型构建、图表交互与文档；用真实本地四只持仓完成首轮研究，报告结果与证据限制。
