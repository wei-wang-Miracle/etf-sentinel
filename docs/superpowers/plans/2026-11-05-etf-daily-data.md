# ETF 日行情实施计划

目标：配置五只标的，历史日行情定时入库并展示日 K。
架构：PostgreSQL 保存配置、行情、任务及区间状态；API 内调度并使用数据库互斥。

1. 创建采集规划、校验测试并验证先失败，再实现数据源及采集服务。
2. 增加 SQLAlchemy 模型、Alembic 迁移、任务接口与调度。
3. 构建标的配置、任务及日 K 页面，接入真实 API。
4. 验证测试、构建、迁移及本地真实数据链路，同步文档。

验证结果：18 项后端测试通过，迁移可升降级且元数据无漂移；前端构建、类型检查、
浏览器交互及真实采集通过。API 镜像可构建；Web 镜像受 Docker Hub 连接限制，
三容器链路未完成。真实增量重跑保持 2,496 条无重复。
