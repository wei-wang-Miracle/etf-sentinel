# 均线策略与统一回测实施计划

用户已确认510500、512100，以均线规则先建立可扩展且可复现的回测。

## 设计与边界

策略研究新增一个统一入口。策略注册表输出名称、参数、版本及通用逐日决策/指标；规则根据当日
及之前数据输出0或100%目标仓位与原因。统一引擎负责翌日开盘成交、费用、
现金、整手、分红应收与到账，买入持有基准使用同引擎同成本同区间。
本次仅实现均线策略，不把国家队和恐贪的未来组合提前实现。

默认60日均线、初始10万元、佣金万一且最低5元、单边滑点万五；均可调整，
均为研究假设而非用户真实费率。两只境内股票ETF仅做多，买入100份整手，
价格最小变动0.001元，成交价按方向取整；现金/费用用Decimal精确到分。
当天收盘产生信号，下一交易日开盘执行；分红不因卖出而丢失登记日权益。
仅有发放日期时按收盘到账，次日开盘才可使用；非交易日发放次交易日开盘反映。
期末按收盘估值并包含未到账应收，不强制平仓，不以复权价格模拟真实买卖。

使用已核对的东方财富分红登记、除息、发放日期和每份金额。日信号使用
原始收盘与除息现金构造的因果含息指数，不依赖尚不明确的源复权字段。
交易日完整性使用带版本的上海交易日历核对；缺日、非法价格、权益未覆盖、
不支持的份额折算或历史异常跳变时拒绝计算。零成交量时因缺少事前停牌资料拒绝整段回测；开盘成交只使用前日决策与开盘价，
固定不利滑点不读取当日盘中高低，不模拟盘口/涨跌停排队或容量。

每次回测不可变入库：参数、策略及引擎版本、输入数据快照、来源、交易日历
版本、输入摘要、逐日权益与仓位、交易与信号原因、成本、基准及回撤。
前端统一选择策略、标的和参数，图表为主；不恢复分析页底部数据明细表。

## 验证结果

2026-11-06本地完成迁移0006，84项后端及启动器测试通过，包含独立测试库集成；
ruff、前端构建/类型检查、Compose配置、两库alembic check及本地文档链接通过。
构建保留大包提醒，Starlette与交易日历依赖有弃用提醒，没有测试跳过。
本地浏览器验证运行保存、两只实验切换、成交解释、预热不足拒绝与快照复算。

引擎1.2、规则1.1，默认成本、60日均线，实际区间2025-01-02至2026-11-05：
510500策略收益12.78355%、基准21.93721%，最大回撤分别16.47511%、29.30364%；
512100策略收益6.46576%、基准15.31231%，最大回撤分别18.88147%、29.65427%。
两组各445个账户交易日，逐日权益恒等式、基准现金分红独立手算与快照复算通过。
本地保存为实验7和8，早期开发版本实验保留但显示旧版提示，不替换历史结果。

独立审查发现并修正：开盘成交读取盘中高低价、横盘均线比较残差、
引擎耦合均线参数；补充发放日现金不提前用于当日开盘的测试和保守到账约定。
这些校验只验证约定下的核算，无法证明二手权益源完整或开盘订单实际可成交。
