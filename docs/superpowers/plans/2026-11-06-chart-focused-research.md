# 标的统一与图表优先实施计划

本次根据用户四项要求直接实施，保留暖纸、宋体标题及暗色主题。

1. 国家队18只与原5只去重为20只；迁移仅插入缺失配置，默认2020-01-01，
   保留已有启停、名称与日期，复用任务1进行行情回填及增量更新。

   标的配置表与任务日志属于操作功能，保留。
4. 验证迁移保留配置与历史、20只日K覆盖、18只比例/K对照、加载/空/错误、
   暗亮主题与窄屏；执行后端测试、构建、类型检查、静态检查及文档检查。

视图主次。沿用主题变量，不增加装饰图形与动画。
