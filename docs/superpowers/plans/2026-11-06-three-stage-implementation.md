# 三期投研功能实施计划

目标：复用现有账户同步、行情、估值和统一回测，实现单标的复盘、研究对象和横向比较。

1. 权益与复盘：增加权益解析、账户交易重建及数据质量校验；用费用、现金流、分红和缺失样例验证。
2. 标准化基线：复用统一回测的持有和均线规则，统一资金、区间、费用和权益；校验不可比状态。
3. 研究对象：组合现有行情、估值、情绪、国家队和账户查询；验证标的映射与缺失降级。
4. 横向对比：比较共同区间内同一维度，缺失或口径不一致不排名；验证缺日与端点规则。
5. 页面和文档：沿用现有图表和主题，增加入口与跨页导航，保留已实现的同步展示。
6. 验证：后端业务测试与静态检查、前端类型检查和构建、编排配置、文档链接；报告未验证链路。

## 实施与验证记录

三期核心入口已经实现，现有账户同步与数据保持。新增迁移0009已在本地业务库与
独立测试库执行；六只有成交ETF的公开权益资料已核验入库。未操作生产环境。

独立测试库全量141项测试通过，无跳过，覆盖现金流恒等式、T+1、子区间、应收、
自然日派息、成本顺序不明、同步覆盖与修复、动态标的、基线原子性和快照复算。
前端类型与构建通过，保留原有大包体积提示；后端静态检查、Compose配置、
本地文档链接与差异空白检查通过。浏览器验证ETF／指数分区、对比图表、旧入口、
键盘、刷新、主题和移动端；未出现页面脚本异常。

当前保守边界：真实核算需明确确认零期初和成交日期；XIRR潜在多解不选根；
份额折算严格拒绝；因子、轮次细化、真实信号归因和全账户现金不在本次实现中。
