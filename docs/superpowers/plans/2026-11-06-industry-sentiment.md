# 行业恐贪实施计划

目标：新增行业恐贪采集与展示；首次五年，后续按已入库日期增量处理。
架构：复用任务配置和运行日志，通过任务编号隔离ETF与恐贪采集；新增类别和日数据表。

1. 核实源接口窗口和日期参数，测试增量规划、零值、范围校验和重复日期。
2. 新增详尽注释的数据库模型和0003迁移，独立任务默认01:10。
3. 实现首次五年、增量窗口、失败不推进、幂等更新及本地查询API。
4. 在现有任务页切换任务，增加行业恐贪概览、双图和历史表。
5. 验证迁移、独立库测试、真实采集及浏览器交互，更新文档和功能地图。

## 实施与验证结果

以上五步已完成，使用迁移0003保留既有ETF数据。

- 首次真实采集八类9751条；第二次均请求一年窗口，各更新六条，总行数不变。
- 独立测试库36项测试通过，包含幂等修订、单类失败、零分、空源、断档与任务隔离。
- Ruff、前端构建及类型检查、Alembic结构一致性、Compose配置检查通过。
- 浏览器验证八卡双图、五年切换、零值、暗亮主题、移动布局、双任务、错误重试、
  空数据以及既有ETF日K。审查发现的目录与序列状态共用问题已复现并修复。
- 本地启动脚本已启动新版API与Web；本次没有验证Docker三服务整体启动。
- 前端构建有包体积提示，测试有既有httpx弃用提示，均未导致检查失败。
