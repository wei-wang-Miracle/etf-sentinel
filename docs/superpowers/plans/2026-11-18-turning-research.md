# 顶底算法新一轮迭代计划

目标：按用户确认的口径，重新进行最多50轮模拟、诊断、调整，争取扣费后完整交易胜率80%。轮内允许比较多组参数；旧搜索不计入本次轮数。

范围归属投研分析，沿用现有K线指标和本地行情，不接自动交易或盘前任务。
每只ETF独立50,000元，整手100份，佣金万一免五、双边滑点5基点，次日开盘执行。

1. 修正账本和多日确认。先增加跳空、资金不足、未平仓、多日等待和因果一致性测试，再实现并运行相关测试。
2. 冻结本地20只ETF行情、按已核验跟踪指数分类，并核验现金分红与折算；折算后重新预热，记录截止日、数据摘要与代码摘要。此前已观察历史不称全新样本外。
3. 执行50轮：前20轮用于修复账本和单规则探索，后30轮按六类轮换比较独立参数。每轮结合亏损交易、持仓时长、错过反转和回撤诊断调整，保存全部候选、得分和下一轮方向。每类至少30笔完整交易才认可80%目标；收益、未平仓和回撤一并报告，不靠盈利才卖或隐藏浮亏达标。
4. 汇总全历史和曾反复观察的近期区间。近期结果是历史诊断，不是独立样本外验证；按跟踪指数说明重复市场暴露。
5. 观察各类代表性盈利／亏损交易K线，生成可复算结果与曲线。按每类拟合参数接入图表，同时注明整体未达80%的结论。
6. 完成只读代码审查、前端构建和类型检查、相关规则及浏览器测试、Compose配置和差异检查，更新README、功能地图和顶底说明。

验收：本次实际轮数和停止原因清晰；全部交易与逐日账本可审计；输入倒序、追加未来数据均不改变已发生信号；信号交替且不删除亏损交易；报告明确成本、分红边界、未平仓、样本数、收益和回撤。

用户已授权连续试错及调整，本计划在当前开发分支执行，保留已有改动，不创建工作区、不自动提交。
