# 策略指标说明实施计划

目标：创建策略时，用户无需离开表单就能理解每个指标的投资含义和实际计算口径。
主归属为策略研究，复用当前条件编辑器；不改变条件计算或策略参数。

## 交互与内容

指标、窗口、类别、比较符或阈值获得焦点时，在该条件下方展开说明，选中指标后
同步更新。保留原生选择器，不依赖系统菜单选项的悬停事件。提供“指标说明／
收起指标说明”按钮，支持键盘及触屏；说明保持可读，不因指针离开而消失。

每项包含投资含义、如何理解、计算方式、数据来源与口径、使用边界。
解释全部十类指标，区分通用金融定义和实际使用的源值，不编造第三方算法。
阈值示例仅解释单位，不推荐买卖参数。不可用指标仍可阅读说明和当前缺失原因。
