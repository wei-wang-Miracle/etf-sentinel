# 当前持仓ETF策略闭环（已下线，历史记录）

> 本文所述固定候选、批次研究与采用观察版本的创建闭环已整体下线：页面、路由
> 和旧创建接口删除，迁移0013清理旧观察链数据（`strategy_version_id`为空的
> 观察、其信号与执行关联及无引用的旧批次）。共用表结构和回测引擎保留。
> 盘前计划、委托匹配与执行核对仍由单ETF流程共用，见[单ETF策略说明](single-etf-strategies.md)。
> 下文为历史口径记录，不再对应可用功能。

**策略回测 → 当前持仓研究与观察**将因子、候选研究、观察版本、每日计划和
真实执行核对放在同一条路径。研究对象只有可交易ETF，关联指数仅提供估值背景。
研究范围默认使用最新完整同步中的配置内正持仓，建立批次后冻结，不随持仓变化改写。

## 从研究到观察

先在投资复盘同步账户，并保证行情和权益资料覆盖研究截止日，再按以下步骤操作。

1. 打开策略回测，核对持仓源日期、各ETF行情和权益核验日期。
2. 使用共同开发／验证区间，运行全部候选并保存批次。首次建议按共同有效区间
   的前70%／后30%分开，两段各从独立研究本金开始，不继承开发期仓位。
3. 切换组合和单ETF，看收益、回撤、水下期、波动、在场时间、换手、成本及退出轮次。
   对比半资金持有参照，辨别减少投入和择时分别带来的影响。
4. 综合两段结果，为每只ETF明确选择一个候选建立观察版本。系统不按收益排名
   自动采用；同ETF采用新版会暂停旧版，原参数、信号和成交关联保留。
5. 盘前生成计划。核对规则原因、数据截止、生成时间、参考份额、真实与可用份额。
   买入先人工核对可用现金。系统不下单。
6. 同步真实成交，选择累计委托，依据券商明细确认成交所属日并填写依据后关联。
   不执行时留下跳过原因；未关联不等于没有实际交易。
7. 定期查看执行偏离和采用后规则重算，再决定是否创建新观察版本。
   看过验证结果后再调参，该区间不再是未见样本；所有批次独立保留。

每只研究账户初始人民币50000元。真实数量、可用份额、实际费用和盈亏仍以
真实同步及复盘核算为准；四只研究账户合计20万元不代表真实投入20万元。
旧单次回测和单ETF复盘研究入口保留可调资金假设，默认也为5万元、万一免五。

## 因子与候选

本版固定少量规则，先检验增量价值，不引入七因子加权或自动搜参。

| 候选 | 规则 | 研究投入 |
| --- | --- | --- |
| 买入持有 | 区间首日开盘买入，现金分红不自动再投 | 50000元 |
| 20日均线 | 含息指数高于MA20持有，否则空仓 | 50000元 |
| 60日均线 | 含息指数高于MA60持有，否则空仓 | 50000元 |
| 趋势与动量确认 | 高于MA60且20日含息动量为正才新入场；跌回MA60退出 | 50000元 |
| 趋势确认半资金 | 相同规则，25000元策略子账户＋25000元零息储备 | 总计50000元 |

20日波动为日含息收益总体标准差乘根号252，仅供风险观察，不参与买卖判定。
动量只确认入场，不在趋势仍成立时单独触发卖出。均线、动量按精确有理数比较，
预热不足不决策。关联指数估值、恐贪和国家队比例仍是背景，修订历史不冒充
原时点已知输入。指数不参与ETF候选、持仓或同维度对象排名。

半资金储备不补仓、不每日再平衡；账户收益、回撤、费用及仓位均按总50000元报告。
独立子账户净值可能随盈亏偏离初始50%投入。真实账户没有独立现金子账，计划
不会假设这25000元储备实际存在或可动用。

## 计算与判断边界

所有候选复用同一注册表和成交引擎：前日收盘决策、次交易日开盘、不利滑点
5基点、买入整手100份、佣金率0.0001且最低0元，权益按登记／除息／派发核算。
不模拟涨跌停排队和全部交易所限制。旧实验按原版本和快照复算，不被新默认值改变。

批次保存持仓范围、源日期、全部候选和失败原因、参数版本、费用假设、两段结果
及独立实验引用。缺失对象不静默剔除；组合要求全部对象及相同交易日齐备，
按等额独立研究账户汇总，不用今天真实仓位权重回填历史。范围来自今天持仓，
回看历史本身存在事后选样，不能因此宣称完整样本外验证。

非支配候选只表示在收益与回撤两个维度上没有被其他候选同时严格改善，不表示
推荐。未替用户设定收益让步／回撤门槛。最长水下期按交易日收盘权益低于此前
历史峰值计数；轮次净盈亏含买卖佣金及应收分红，未平仓不凑成完整轮次。
组合轮次数为各ETF之和，不代表独立样本数量。

## 计划时点与真实执行

任务5默认北京时间08:30独立运行，可在定时任务页暂停或修改时间，也可手动生成。
计划只为下个尚未开盘交易日生成；交易日开盘后禁止补写当日计划。获得观察锁后
和计算结束时都重新核验时间，不能用请求开始时刻伪装盘前生成。周末可为下个
交易日计划，但前一完整交易日行情、权益及真实仓位仍须通过新鲜度校验。

仅使用生成前已采集的完整行情与权益，保存实际生成时间、数据截止、冻结输入、
规则版本、条件与摘要。缺失、迟到、过期和预热不足均显示阻断原因。相同观察版本
和执行日幂等；后来的采集不会改写既有计划。

新建仓参考份额按研究预算、决策收盘及成本估算；持续持有时沿用本轮参考份额，
不随每日价格重算补减仓。规则退出后重新入场才开启新一轮估算。参考份额不是
次日开盘实际可成交数量，也不保证真实现金路径与回测账户一致；实际份额另列。
卖出受同步可用份额约束，买入标记待现金核验，不推断券商可用现金。

委托号是累计记录，不是逐笔成交。匹配候选不自动确认执行；人工关联须确认日期、
标的、方向、计划在先和依据，一条委托最多关联一个计划。状态区分未确认、部分、
数量一致、超额、零成交、无需调整和主动跳过；源数量修订后重新核对并提示变化。
真实费用已在账户记录中，不再扣一次。暂停不删除历史，也不把旧计划视为已成交。

采用后规则重算只使用采用日期之后的完整交易日，明确标为按当前数据重算。
它不等于真实交易收益，也不是当时日计划驱动的前向账户业绩。真实收益仍在投资
复盘按现金流核算，不把固定研究本金净值与实际XIRR混排成超额收益。

## 存储与接口

迁移0010增加研究批次、观察版本、日计划和人工执行关联，任务配置与锁独立；
0011为账户同步增加完整持仓集合证据。集合与明细在同一SQL快照读取，同日再次
同步后消失的ETF不保留为当前正仓；完整空集合不回退历史仓位。旧同步无集合证据
时兼容原历史日期逻辑，重新完整同步后取得严格集合证据。
