# 指数估值

指数估值属于投研分析，依赖数据基础的独立日频采集。当前20只ETF关联8个指数，
同一指数只采一次；不改动现有策略或回测输入。

## 使用方式

在**指数估值**页选择关联ETF或指数，切换市盈率、市净率、股息率、净资产收益率、
股债风险溢价差值。主要数值之后展示估值/指数点位对照及本地回看分位，下方为独立
指数日K和成交量。指数点位不是ETF价格，页面不展示底部全量数据明细。

点击**采集与调度**进入独立任务4，默认北京时间每日01:30，可手动采集、暂停、
修改时间和查看最近20次运行。估值无需凭据，指数日K使用后端已有ChatBI配置；
无行情凭据时仍采集估值，运行标为部分失败，不假报全部成功。
页面加载只查询本地数据库，不调用外部源。

## 来源和更新

估值来自`https://ai2.jiucaishuo.com/api/index-valuation`公共GET接口。
页面规模/精选是同一指数池的两个分类，不重复建立采集任务。

- 列表：`?category=gm`和`?category=jx`，仅保存相关8指数。
- 详情：`/detail?code=000905.SH`，保留来源摘要与统计证据。
- 历史：`/history?code=000905.SH&metric=pe`。
  五类指标键为`pe`、`pb`、`xilv`、`roe`、`premium_diff`。
- 指数日K：ChatBI `daily_ohlcv_index`，只在后端查询，使用六位查询代码。

估值历史接口没有已核实的日期窗口参数，每日完整读取并核验，数据库按
指数/指标/源日期仅写新增或修订，未变不改采集时间。
新增和修订均保存前后值、有效状态、观测时刻及运行编号。
来源概览、详情和整段统计按相邻内容变化归档；失败时保留此前完整快照。

窗口内源缺日或尾部倒退会拒绝该指标本次写入。只有已超过十日历年边界的旧点
不再返回，且新源仍与本地重叠且尾部不倒退时，允许继续新增并保留本地旧点；
运行日志明确该规则。单指标失败不阻塞其他指标。

指数日K从最早有效估值日按月查询至北京时间昨日，成功窗口保存；后续增量并
重查最近七日。复查失败撤销水位等待重试。有有效估值日期却缺对应日K时，
整个请求区间明确失败，不写成功水位；已有空窗口也检查本地缺口后回补。
无估值样本的空查询可以记录成功，但不代表交易日完整性已验证。
不造OHLC或用收盘值填充缺失开高低。

## 数值和分位口径

历史PE/PB单位为倍，股息率和ROE为百分数，风险溢价差值为百分点。
源列表ROE为小数，历史ROE已经是百分数；页面采用历史值，不重复乘100。
PE具体算法、是否TTM及风险溢价的国债期限未经源证实，不自行猜测或重建。

PE/PB非正值、负股息率标为不适用；保留原始值但不参与分位。
零股息率有效，ROE和风险溢价允许为负。源缺失不补零。
本地以18位小数保存源十进制值（当前ROE源最多16位小数），不用四舍五入后的显示数值重算分位。

**本地回看分位**逐日按截至当日、最多往前十个日历年内的有效观测（含当日）计算：
`100 × 严格小于当日值的样本数 / 有效样本总数`。
同值不计入分子。显示区间在计算之后过滤，改日期不会改变同一天的分位。
历史不足十年时显示实际覆盖及样本数，不冒充十年。

**来源概览分位**单独标注，可能受来源截断精度及统计口径影响，未提供则为空。
历史响应顶层分位和阈值只是当前返回整段统计，不回填成过去每一天的分位。
高股息率分位不自动等同高估，没有复制外站多配/少配推荐。

本地历史可能被后续修订，缺少原始历史发布版本，因此逐日计算仅代表按当前
已采历史回看，不证明原时点已可获得，不直接接入策略回测。

## 本地接口和存储

接口仅允许已经配置的8个关联指数，代码或指标不合法会明确拒绝。

| 接口 | 用途 |
| --- | --- |
| `GET /index-valuations` | 目录、ETF关联、五指标最新值/覆盖、分位及最近运行状态 |
| `GET /index-valuations/series/{index_code}?metric=pe&start=...&end=...` | 本地估值、因果窗口分位及独立指数日K |
| `GET/PUT /index-valuations/job` | 独立任务配置、最近20条运行记录 |
| `POST /index-valuations/job/run` | 手动异步运行；重入返回409 |

七张业务表及字段见[数据库说明](database.md)，接口调查及范围决策见
[设计记录](superpowers/specs/2026-11-06-index-valuation-design.md)。
本版不采分时、盈利预测、全量成分股或相关性矩阵。

## 已验证覆盖与限制

2026-11-06本地真实采集五指标共84,950条，源最新2026-11-05。
普通宽基多数从2016-11-07开始，部分ROE缺两天；科创50从2019-12-31开始，
其股息率从2020-05-07开始；中证2000从2023-08-11开始。

已入库指数日K共17,007条；普通宽基多数2428条，科创50为1657条，
中证2000为782条。第二次真实采集的估值新增与修订均为0。

科创50的2019-12-31源日K只有收盘1000点，开盘/最高/最低为空，不能形成有效K线。
该区间保留失败、可重试，不伪造价格；因此任务可能显示部分失败，页面可见实际
覆盖，其他指数和估值仍正常入库。来源接口实测可用不保证长期稳定或财务口径权威。
