# ETF 历史日行情

本期提供标的配置、定时采集及日 K 展示。设计边界见
[首期设计](superpowers/specs/2026-11-05-etf-daily-data-design.md)。

## 页面使用

先在标的配置页检查20只标的的采集开关与起始日期，再到任务页运行采集。

1. 标的配置：首期固定 `510500`、`512100`、`159531`、`159205`、`588080`。
   可以启停采集、设置起点，查看实际入库条数与覆盖日期。名称由源接口更新。
2. 定时任务：默认北京时间每日 01:00，运行截至昨日的历史行情。
   支持修改时间、暂停定时、立即采集和查看每个请求区间的日志。
3. 行情展示：选择标的与日期范围，查看日 K 与成交量，悬停读取同日数据。
   滚轮及底部滑块可缩放图表；主题按钮切换暗色与亮色。

停用标的不删除行情，暂停定时不影响手动采集。配置修改不影响已开始运行的
配置快照，下次运行使用最新配置。调早历史起点会回补更早区间，调晚不删除历史。

## 数据处理口径

外部接口 `daily_ohlcv_etf` 仅用于后台采集。页面查询只读取本地 PostgreSQL。

- 首次从配置起点按自然月查询，成功区间单独提交。默认起点为 2020-01-01。
- 后续跳过已成功的旧区间，重查近期七日附近的交叠区间，并继续未完成月份。
- 失败区间不推进进度，下次任务重试；一只标的或月份失败不阻止其他区间。
- 网络错误、HTTP 429 或 5xx 最多尝试三次；鉴权错误不作网络重试。
- 以代码和日期联合唯一约束更新行情，重跑不重复入库；源修订覆盖原值。
- 空响应保留请求区间和零条结果，不生成行情，不代表已验证数据完整。
- 入库前校验日期、标的、必要数值、价格高低关系；单个区间的数据统一校验后入库。
- 展示源原始开高低收，保留源复权收盘字段，但不推断复权 OHLC 或复权方式。
- 成交量与成交额保留源数值，单位尚待数据源确认；不擅自转换为手、股或万元。
- 行情保存源更新时间和本地采集时间。最新入库日期不代表覆盖所有历史交易日。

API 内调度每 30 秒检查一次；当天已过执行时间且未运行时会补触发一次。
跨 API 进程使用 PostgreSQL 会话锁互斥，运行配置与日志存库。
应用重启将失去活跃锁的运行标记为中断，已成功提交的区间保留；
下次手动或定时运行继续未完成区间。应用未运行时不会执行定时任务。

## 环境变量与数据库

在根目录 `.env` 配置数据源凭据，保持该文件不被提交。

| 变量 | 说明 |
| --- | --- |
| `CHATBI_URL` | 数据源地址，默认指向已验证的 ChatBI API |
| `CHATBI_ACCESS_CODE` | 用户提供的访问码，示例文件留空 |
| `CHATBI_TOKEN` | Bearer token，仅填写 token 本体，不含 `Bearer ` 前缀 |
| `PGHOST` / `PGPORT` | 本地开发连接的 PostgreSQL 地址和端口 |
| `PGUSER` / `PGPASSWORD` / `PGDATABASE` | 数据库用户、口令与库名 |

数据库用户、口令与库名在未指定 PG 变量时，回退读取 `.env` 的对应
`POSTGRES_USER`、`POSTGRES_PASSWORD`、`POSTGRES_DB`。
Compose 内会显式注入容器数据库参数，不使用本机 PGHOST 或 PGPORT。
数据源客户端直接连接目标地址，不继承系统 HTTP 代理，且不跟随鉴权重定向。

容器启动先执行 `alembic upgrade head`；本地开发需要手动执行迁移。
当前迁移创建标的、日行情、任务配置、运行记录和成功采集区间五张表。
后续语义命名迁移将物理列统一为明确业务名并添加详尽注释，见[数据库说明](database.md)。
迁移不连接外部行情源，不修改任何外部生产数据库。

## API

以下路径是 API 直连路径，前端访问时添加 `/api` 前缀。

| 方法及路径 | 用途 |
| --- | --- |
| `GET /instruments` | 配置与入库覆盖范围 |
| `PUT /instruments/{code}` | 保存 `enabled` 和 `start_date` |
| `GET /job` | 任务配置、下次执行时间和最近 20 次运行及区间日志 |
| `PUT /job` | 保存 `enabled` 和北京时间 `time`，格式为 HH:mm |
| `POST /job/run` | 异步触发，返回 202 和运行编号；已有任务返回 409 |
| `GET /candles/{code}?start=YYYY-MM-DD&end=YYYY-MM-DD` | 查询闭区间本地行情 |

## 验证记录

2026-11-05 在独立本地 PostgreSQL 上验证迁移及真实源数据采集。
五只标的共入库 2,496 条，最新行情日均为 2026-11-04。
`159205` 最早返回 2025-06-12，其他四只最早返回 2024-08-12。
以上是本次接口返回范围，不推断上市日期或数据源完整历史能力。

真实增量重跑只查询 10 个近期区间，入库条数保持 2,496，重复触发返回 409。

18 项模拟源与独立测试库用例验证幂等修订、失败重试、空响应、非法数据、配置、任务锁、
重启恢复与按日调度。浏览器验证日 K、配置保存、日志、暗亮主题和移动布局。
API 镜像构建成功，并验证容器内 Python 3.12 导入和数据库连接。
Docker Hub 连接拒绝导致 Web 基础镜像获取失败，三容器启动链路尚未验证。

## 统一研究标的

迁移0005将国家队18只ETF与原五只去重为20只，新标的默认启用并从2020-01-01
按月回填，已有名称、启停及起点不覆盖。所有标的复用任务1、区间日志及失败重试。
起点早于上市日允许空响应，不生成虚拟日K；真实覆盖以入库源交易日为准。
行情页使用紧凑下拉选择，不显示底部明细表。

当前最早源行情为2024-08-12，部分新上市ETF更晚。配置2020年起点不意味着源
保证从2020年提供记录。首次回填的两个网络失败区间已在后续任务重试成功。
