# ETF多因子汇总信号：50轮研究结果

本轮完整执行50轮，独立于此前顶底算法的50轮。全历史拟合达到166胜／187笔完整交易，
胜率88.8%；最近已观察区间只有27胜／42笔（64.3%）。因此结论是：**历史拟合达到总体目标，
尚未证明能泛化到未来，也未达到全部ETF均80%的目标**。

## 功能归属与数据

主归属为策略研究，依赖投研分析的顶底因子、数据基础的ETF行情和关联指数估值，
交易与分红使用现有统一回测引擎。本报告记录的是离线研究，最终逐 ETF 规则在算法库中作为
[ETF多因子择时（实验）](single-etf-strategies.md#etf多因子择时实验)供回测和绑定。现有 K 线上的顶底确认仍是原有分析指标。本轮含息顶底因子与汇总买卖信号绘于独立研究图。

输入来自本地数据库只读一致性快照，包含20只ETF真实日行情、唯一跟踪指数映射、
PE/PB历史及现金分红证据。按现有交易日历和权益校验，缺日、重复、无效OHLC、
非正成交量及复权因子不能核验时拒绝计算。159922、159977、510310从区间内最后一次
份额折算后的首个交易日重新预热；最少先有60条行情，较长均线另需相应预热。
首个允许决策的位置为第61条，次日才允许执行；全体计值最早从2024-11-14开始。

本次十只权益页面成功读取，另十只因源暂不可用回退到此前冻结原始页面，
全部重新解析并通过现有行情的权益一致性检查。具体回退记录见本地`actions-*.json`；
其中缺失的原采集时间保留为空，不伪造时间，也不能将缓存说成重新获取的完整最新证据。
完整输入含来源日期、采集时间、权益证据和SHA256摘要；没有修改本地数据库。
行情、权益和估值都是当前可获取的历史副本，可能经过源修订，未证明历史决策日已知。

PE/PB分位使用唯一关联指数，截至源日的十日历年内有效观测中严格小于当前值的比例。
历史不足十年时使用已有历史；非正PE/PB不参与分位。决策只取前一ETF交易日的精确源日期值，
缺日不向前填充。估值缺失时含估值规则禁止新开仓，但已有仓位仍可退出。
估值是源可修订历史，延迟一交易日不能证明当时已经发布。最终四只规则使用PE分位，
没有最终规则选择PB。现有恐贪缺少宽基ETF对应类别，国家队数据仅始于2026年且缺两只，
因此本轮未将它们强行纳入，也没有新增外部数据源。

## 因子与最终信号口径

算法按时间正序，只读取当前及以前的数据，不把事后局部最低价／最高价回填成信号。
价格类因子使用按已核实当日除息现金构造的含息指数；成交仍用原始开盘价格。
本报告形成时，顶底因子使用了已退役的`slope-structure-paired-v3`默认参数和当时的研究导出流程，因此不应被当作现行统一顶底因子的结果。现行系统使用`slope-structure-paired-v4`服务端因子引擎，按ETF冻结参数模板并保持底顶交替；它仍只贡献汇总规则的一部分。新研究通过[`export_turning_factors.py`](../scripts/export_turning_factors.py)冻结当前因子事件，历史前缀检查不改变过去确认。

`bias(N)`是含息收盘／N日简单均线-1；`mom(N)`是含息收盘／N日前收盘-1。
RSI使用最近N次含息指数变动的正变动总和／绝对变动总和×100，无变动取50，
不是Wilder平滑。量比为当日成交量／此前20日均量，分母不含当日；源成交量单位待确认，
比值沿用同序列单位。突破使用此前W日最高含息收盘，不含当日，不是最高价突破。

每只ETF先选择以下一种结构作为必要条件：

| 规则族 | 必要结构条件 |
| --- | --- |
| 底部结构 | 最近`event_age`日内存在底部确认，年龄0包含当日 |
| 超跌结构 | RSI≤`rsi_buy`，或`bias(20)`≤`-dip` |
| 均线回踩 | `bias(fast)`≤`-dip` |
| 收盘突破 | 含息收盘严格高于此前`break_window`日最高含息收盘 |
| 综合结构 | 最近底部确认、RSI超跌、20日均线负乖离三者任一满足 |

入场票按“结构成立、`mom(recovery)>0`、`bias(slow)≥trend_floor`、量比≥`volume_min`”
各一票；选估值时加“PE/PB分位≤`value_max`”一票。必要结构成立、票数≥`buy_votes`、
估值门槛通过（若选用）、风险票未达退出阈值且冷却结束，才产生最终目标满仓信号。
**投票并不要求每一票都满足**；结构是必需，估值被选用时也是硬门槛，恢复／趋势／量能
则按阈值竞争贡献。故两票规则不能解读成同时通过趋势和量能验证；启用估值的两票规则，
可能仅由结构票与估值票满足入场。这是本轮冻结口径，并非每个因子都被证明有增益。

风险票共三票：最近`event_age`日顶部确认；低于`exit_ma`日均线且3日动量为负；
RSI≥`rsi_sell`且1日动量为负。持仓风险票数≥`sell_votes`时产生最终空仓信号。
另外，止损、止盈、移动回撤或最长持有期任一触发，也产生同一个最终卖出信号。
空仓时风险票达到阈值会阻止买入；持仓时卖出优先。

风险收益为“收盘价加本轮持仓已获得的除息现金／实际含滑点买入价-1”，
登记日冻结权益、除息日才将相应现金计入风险收益，不在登记日提前增加收益。
止损阈值`stop_loss`、止盈`take_profit`不扣佣金；完整交易胜负扣佣金。
移动退出是从本轮收盘收益峰值回落`trailing`个百分点，峰值至少为0；
它不是当日最高价跟踪，也不是从盘中高点按比例回撤。持有期含买入当日，达到
`max_holding`日收盘发卖出信号，次日开盘成交。卖出执行当日记为冷却第0日，
其后超过`cooldown`个交易日的收盘才可新发买入信号。

交易只执行最终汇总目标：T日收盘产生信号，T+1交易日开盘执行；原始开盘加减单边滑点，
再按0.001元向不利方向取整；100份整手、佣金万分之一、最低佣金0元，资金不足会减手，现金不为负。
保持持有不会每日按金额调仓。收盘止损不保证按止损价成交，隔夜跳空会扩大亏损。
现金分红按登记、除息、支付日记入统一账户；不把信号当成真实成交。

胜单为完整卖出净收入加归属持仓的分红应收，严格超过买入总支出；持平算非胜单。
期末未平仓单列净浮盈亏，未假设卖出，因此没有扣尚未发生的卖出佣金和滑点。

## 50轮如何执行

每轮都对20只ETF读取当前规则、模拟并诊断亏损，比较围绕当前规则生成的候选，
再模拟、评分和保存。诊断统计快速亏损和曾出现超过2%原始价格有利波动后亏损的交易；
后者过半时优先研究退出参数，否则研究入场参数，同时每轮有固定随机种子的两至三项扰动。
诊断仅用于下一次历史研究，不进入当日策略信号；退出日盘中极值也只作为事后诊断，
不作为可成交价或信号因子。

第1轮额外比较五个规则族。每轮是一次全体诊断、候选比较与规则选择，轮内可有多组候选，
不是每测一组参数算一轮。50轮共记录11,542次逐ETF候选评估（含当前规则和重复候选，
重复结果缓存），不等于11,542个独立新策略。第8轮总体首次超过80%，继续到50轮以
尝试逐ETF门槛，最终19只达到，512100的已评估候选中没有满足最低5笔且80%的规则。

评分口径冻结如下：完整交易不足5笔时为`-2 + .1×笔数 + .05×收益率`；否则为
`min(.8,胜率) + .08×min(.5,收益率) + .12×最大回撤 - .2×max(0,-浮盈亏/50000)`。
回撤为负数。达到80%后不继续奖励更高胜率，转向收益、回撤和浮亏；评分并非强制
所有选择都满足80%，最终是否达标另行逐只核查。全体已研究历史参与评分，未保留新的
未见测试集，因此循环只能说明对这段历史的拟合能力。
