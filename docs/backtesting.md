# 策略与回测

当前主流程已调整为三入口和自定义单ETF策略，见[单ETF策略说明](single-etf-strategies.md)。下文保留原回测引擎与历史实验口径。

策略研究使用一个注册表和一套日频账户引擎，供单ETF策略比较与真实复盘共用。
已实现持有、均线趋势、趋势与动量入场确认；资格扩展到全部配置内ETF，
每次实验仍必须通过权益源、行情覆盖、日历和预热校验。选择标的不代表已通过校验。

## 使用方式

旧“单次回测与历史实验”页面与持仓候选研究入口已下线。回测现在在单ETF策略
创建流程的“回测比较”阶段运行：配置条件后与同ETF已保存版本、持有参照统一
比较，输入冻结入库，见[单ETF策略说明](single-etf-strategies.md)。
本文保留引擎与核算口径。

每次实验仍必须通过权益源、行情覆盖、日历和预热校验。首次使用或把截止日期
延后至权益资料读取日之后，先在数据管理点击**更新分红资料**。
资料获取失败保留已有记录，不把空页面当成没有分红。更新不改写旧实验。
行情仍使用现有ETF任务采集；分红资料本版手动更新，没有新增定时任务。

默认5万元资金、单边佣金万一且最低0元、单边滑点5基点（0.05%）。
这些是可修改的研究假设，不代表实际账户费率。
开始日前至少需要N个已完成交易日，交易日外的起止日期向区间内实际行情对齐，
结果显示实际起止日。截止日必须早于今天；不能以缺失尾部行情计算较短区间。

比较视图展示策略与基准收益、最大回撤、成本及模拟买卖点；
买入、卖出标记落在执行交易日，可查看信号日期、原因、价格、份额及费用。
保存版本关联的实验读取原结果，行情源修订不影响已保存比较。

## 规则与时间边界

均线趋势使用当日及此前的含息指数；高于N日简单均线则目标满仓，否则空仓。
均线含当日，等于时空仓。收盘形成决策，下一交易日开盘执行；
预热期只算指标，不持仓、不计收益。不会把期末收盘决策当成已成交。

指数首值100，此后按 `I_t = I_(t-1) × (C_t + D_t) / C_(t-1)` 递推。
`C`为原始收盘，`D`为当日除息每份现金。使用精确有理数计算并比较，
显示时转换十进制，避免递推和滚动均线的浮点/十进制残差制造横盘信号。
该指数假设除息日再投，只作趋势指标；实际账户按发放日收到现金，二者不同。

规则注册于 [strategies.py](../api/app/strategies.py)：元数据描述中文名称、
版本及整数参数约束，准备函数输出每日决策与通用指标。
[引擎](../api/app/backtest.py)只消费目标仓位、原因与指标，不识别均线参数。
增加规则扩展注册与数据准备，复用参数表单、成交、费用、账户、指标及实验存储；
本版账户目标仅支持0/100%，不提前实现任意仓位或组合调仓。

趋势确认规则只在新入场时增加20日正动量条件，趋势跌回均线时退出。半资金研究
通过25000元引擎子账户加25000元独立零息储备实现，按总50000元重算绩效，
不改变原引擎的空满仓规则。旧快照保持原版本、参数和默认值，不受新界面默认影响。

国家队比例与恐贪尚未接入规则。历史比例会修订，源日期不等于可获得时间；
组合前须明确发布时间、可用延迟和历史版本，不能把今天获取的修订序列
直接当作当年已知输入。缺少指标时也不能擅自补零或无限向前填充。

## 成交与账户口径

当前配置为境内股票ETF，本版仅做多、无杠杆。模拟约定如下：

- 原始开盘价加固定不利滑点，买入向上、卖出向下取整至0.001元。
  不用当天盘中高低价决定开盘是否成交，也不用复权价格模拟买卖。
  滑点是成本假设，可能超出当日实际范围；不声称该价格一定可成交。
- 买入100份整手，预留佣金，资金不足一手及费用时不成交并记录原因。
  满仓信号且已有持仓时保持，不持续再平衡；分红现金不自动再投。
- 金额使用Decimal，成交额、佣金、分红、账户权益四舍五入至人民币分。
  仅计显式佣金和滑点，不收股票印花税，不另估未给定的费用。
  滑点已包含在成交价格和收益中，展示成本不再重复扣除。
- 登记日收盘份额确定分红权益，除息日计应收，发放日转为现金。
  源只有发放日期，没有到账时刻；交易日按收盘到账，下一交易日开盘才可使用。
  非交易日发放在下一账户交易日开盘反映；卖出不丢已登记权益。
  回测开始前没有持仓，因此无开始前登记的权益。
- 每日权益等于现金、原始收盘市值和未到账应收分红之和。
  期末按收盘估值，不强平、不额外扣假设卖出费用。
- 买入持有使用相同函数、资金、区间、分红及成本，首次开盘尝试买入后持有。
  每笔策略成交由前一交易日决策触发，符合本版无日内反向交易的边界。

现有日K不能确定开盘停牌状态、涨跌停排队或盘口容量。
发现零成交量时整段拒绝回测，要求补齐资料；不是用全天成交量推测开盘订单。
正成交量不证明开盘可成交，结果依赖上述简化假设，未模拟真实撮合及市场冲击。

## 数据校验与可复现性

行情来自本地财通证券历史日行情；权益来自东方财富公开基金分红送配页面。
保留登记、除息、发放日期及每份现金，源每十份金额除以10转换。
来源是二手公开表，并未逐条核对基金公司公告；资料读取日期不是完整性保证。

输入检查使用固定版本 `exchange-calendars==4.13.2` 的上海交易日历，
比对包括预热期的完整日期。拒绝缺日、重复或非交易日、非法OHLC、
无效成交量、缺少复权校验字段、区间内份额折算及未解释的复权因子跳变。
源复权收盘口径未确认，只用相邻因子变化与现金除息交叉校验，
相对误差容忍0.0004以容纳源舍入；不作为成交价格或最终收益来源。
校验通过不能保证识别极小的遗漏权益，不能据此宣称源数据绝对准确。

迁移0006创建以下本地表，保留既有行情：

- `backtest_sources`保存配置内基金最新权益、原页面、摘要及读取时点。
- `backtest_runs`保存成功实验的参数、全部输入行情（含预热和采集时间）、
  权益及原始来源证据、日历与引擎/规则/数据版本、规范输入SHA256和完整结果。

创建实验以可重复读事务取得行情和权益的一致快照。实验没有覆盖更新接口，
后续采集修订不影响原结果。快照保留引擎/规则/数据版本与规范输入SHA256；
复算必须版本一致并校验摘要，不能用新引擎假称复现旧版本。

总收益为期末权益相对初始资金；最大回撤把初始资金纳入历史峰值。
年化收益按实际日历天数折算，区间不足365天留空；波动按日收益总体标准差
乘以根号252，包括首日收盘相对初始资金的收益。换手为双边成交额/初始资金。
不把总收益差称为经风险调整的超额收益，也不对短样本推断长期有效性。

## 接口与验证

对外接口均位于 `/backtests`，无自动下单或实时信号推送；实验创建、列表、
详情与复算接口已随旧单次回测下线，实验由策略比较与复盘内部统一创建和读取：

| 方法与路径 | 用途 |
| --- | --- |
| `GET /backtests/catalog` | 策略元数据与配置内ETF本地覆盖 |
| `POST /backtests/sources/refresh` | 可按instrument_code更新单标的；未指定时全部配置源成功后原子更新 |

内部回测请求（`BacktestRequest`）中的日期只是研究区间，预热行情由后端读取：

```json
{
  "instrument_code": "510500",
  "strategy_key": "ma_trend",
  "parameters": {"window": 60},
  "start_date": "2025-01-01",
  "end_date": "2026-11-05",
  "initial_cash": "100000",
  "commission_rate": "0.0001",
  "minimum_commission": "5",
  "slippage_bps": "5"
}
```

[引擎测试](../api/tests/test_backtest.py)覆盖可手算账本、次日成交、
分红登记/应收/发放、手续费整手及期末持仓、无未来价格影响、横盘等值边界，
并验证测试规则无需均线字段即可复用引擎。
[数据测试](../api/tests/test_backtest_data.py)覆盖权益解析及质量拒绝。
[集成测试](../api/tests/test_backtest_database.py)仅在独立测试库执行，
验证快照入库、行情修订后复算不变、预热/缺日/参数拒绝。

配置内标的资格现已动态扩展，复盘四基线使用相同引擎；详见[投研工作台说明](research-workbench.md)。
