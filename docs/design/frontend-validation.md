# 前端研究案卷实施验收

2026-11-07，用户批准实施[总设计](../../DESIGN.md)。主归属为工程基础，
协作投研分析、策略研究、信号与提示、投资记录与复盘、数据基础。
本轮沿用现有接口与业务规则，仅调整前端组织、交互状态和展示。

## 交付范围

| 方面 | 已实施结果 |
| --- | --- |
| 风格 | 保留暖纸亮色、暗色终端、宋体标题与朱红主操作；中性选中态、语义色分离 |
| 样式 | 单一对象头、证据日期带、紧凑筛选与连续指标；图表独立六色、均线主题适配 |
| 动线 | 三主入口保留ETF及日期；列表搜索范围、业务Tab、管理分类与任务恢复；安全返回原任务 |
| 一致性 | 统一Tab键盘行为、对象选择、按钮与状态；清理设计契约中蓝色操作、旧侧栏与手机只读等冲突 |
| 友好性 | 独立读取失败、真实空仓与未知分开；日期文字读数、窄屏文字导航、固定帮助区及明确启用确认 |

ETF详情将行情、关联估值、国家队和情绪作为互斥图表维度；真实操作与每日信号独立。
真实复盘的核算结论和模拟研究分开，已有资金基线主动展开；复盘或行情读取失败互不吞掉另一方。
跨ETF比较移除未实现因子入口，对象选择折叠，覆盖矩阵保留失败对象。

策略采用配置规则、回测比较、保存与启用三阶段。历史比较使用冻结规则和成本，
返回保留当前草稿；保存版本只读，修改产生新版。配置变化后旧结果不能保存或启用。
保存成功但启用失败仅重试同一版本；操作成功后列表刷新失败单独提示。
新策略沿用有效研究链接日期，已有草稿或版本优先并说明日期差异。

每日信号采用摘要与完整详情分工。适用计划与历史记录分开，未知仓位只给方向，
不推定零仓；策略状态或信号读取失败时不将旧数据继续列为适用计划。
保留人工核对与源修订信息，不改变服务端交易窗口，不新增客户端交易日推断。

真实数据走查仅访问本机现有服务，浏览器额外拦截所有API非GET／HEAD请求。
未访问外部生产服务，未触发真实同步、回测、任务执行、策略启用或成交确认。

- `web/`：`npm run build`、`npm run typecheck`通过。
- `web/`：`npm run test:e2e -- --reporter=line --workers=2`，41项浏览器回归通过。
- 根目录：`docker compose --env-file .env.example config --quiet`通过。
- `git diff --check`及本次Markdown本地文件链接检查通过。
- 独立规格审查及质量审查完成；历史快照、操作成功后刷新失败、跨ETF版本链接、
  日期沿用及失败状态下旧计划分类等问题已修复并加入回归。
